Цей додаток допоможе спрогнозувати ціну на оренду квартири в США за вашими параметрами.

Ця інструкція допоможе вам запустити проєкт на вашому комп'ютері. 

## Крок 1. Завантажте код
Відкрийте сторінку репозиторію на GitHub. Знайдіть велику зелену кнопку "Code". Натисніть на неї. У меню виберіть пункт "Download ZIP". Збережіть файл на комп'ютер.

## Крок 2. Відкрийте програму
Запустіть середовище розробки. Натисніть кнопку "Open" на головному екрані. Знайдіть вашу розпаковану папку. Відкрийте її. Завантажте усі файли проєкту.

## Крок 3. Налаштуйте середовище
Знайдіть вкладку "Terminal". Натисніть на неї. Тепер створіть ізольоване середовище для безпечної роботи. Введіть цю команду і натисніть Enter:
`python -m venv .venv`

Активуйте створене середовище цією командою:
`.venv\Scripts\activate`

## Крок 4. Встановіть бібліотеки
Скопіюйте цю команду в термінал і натисніть Enter:
`pip install django pandas scikit-learn joblib psycopg2`

## Крок 5. Підключіть базу даних
Проєкт використовує базу PostgreSQL. 
1. Відкрийте програму pgAdmin на вашому комп'ютері.
2. Створіть нову порожню базу. Назвіть її `rent_db`.
3. Поверніться у ваше середовище розробки. Знайдіть файл `settings.py` у папці `FinalProject`.
4. Знайдіть слово `DATABASES`. Впишіть туди ваш стандартний логін та пароль від PostgreSQL.

Після цього підготуйте таблиці. Введіть у термінал команду:
`python manage.py migrate`

## Крок 6. Запустіть сайт
Увімкніть сервер останньою командою:
`python manage.py runserver`

У терміналі з'явиться посилання. Натисніть на нього. Ваш браузер відкриє готову сторінку сайту.
